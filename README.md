# ⌨️ SCP:SL Bind Editor

![Style](https://img.shields.io/badge/Style-FLXP--Project-8a2be2?style=for-the-badge)

Специализированная утилита для визуального редактирования консольных биндов в игре **SCP: Secret Laboratory**. Позволяет настраивать привязку команд к клавишам через интерактивный интерфейс.

## 🛡 О проекте

Обычный и удобный помощник для создания биндов. Вам больше не нужно искать в интернете таблицы с кодами кнопок и вручную прописывать цифры в файлы - достаточно просто кликнуть по нужной клавише на экране, ввести команду и сохранить.

> [!IMPORTANT]
> **ПРИМЕЧАНИЕ:** Для работы биндов в игре итоговый файл должен называться строго `cmdbinding.txt` и находиться в папке конфигурации SCP:SL.

---

## 🔥 Как это упрощает работу?

1.  **Визуальный маппинг:** Интерактивная клавиатура с поддержкой Numpad и дополнительных кнопок мыши (M4, M5).
2.  **Двойной контроль:** В списке активных биндов отображается и код Unity, и понятное название клавиши (например, `289:emotion Happy (F8)`).
3.  **Импорт/Экспорт:** Возможность загрузить уже существующий файл `cmdbinding.txt`, отредактировать его и сохранить обратно.
4.  **Zero-Syntax:** Система автоматически переводит названия клавиш в понятные игре числовые идентификаторы.
5.  **Smart UI:** Интерфейс подсвечивает клавиши, на которых уже установлены команды, чтобы избежать конфликтов.
6.  **Быстрый бинд через консоль:** Интерактивное поле генерации строки `cmdbind ...` позволяет мгновенно скопировать готовую команду в один клик для ручного ввода в консоль игры (~).

## 🚀 Функционал

* **Keyboard Layout:** Полная раскладка (100%) + Numpad блок.
* **External Input:** Поддержка биндов на боковые кнопки мыши и колесико.
* **Active Database:** Удобный список всех назначенных команд с возможностью быстрой навигации.
* **Wipe System:** Инструкция по быстрому сбросу настроек и очистке конфигурационных файлов.
* **Console Quick Copy:** Интерактивный генератор однострочных команд для быстрого применения настроек прямо на сервере без перезаписи файлов.
* **Система валидации и безопасности:**
  * Установлен строгий запрет на бинд системных и неопознанных клавиш: **Esc**, **Пробел (Space)** и **???** (например, кнопка `Win`).
  * Сайт автоматически отклонит сохранение или импорт таких кнопок во избежание блокировки внутриигрового меню и поломки прыжков.
  * Реализована визуальная индикация ошибок с помощью динамических Toast-уведомлений и красной подсветки ошибочного поля ввода.
* **Adaptive UI:** Премиальный темный интерфейс в стиле Glassmorphism, вдохновленный дизайном FLX-Project.
